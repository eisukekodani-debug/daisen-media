# AIインタビュー　セットアップ手順

APIキーの発行と貼りつけは、小谷さん本人が行う。ほかはClaudeが手伝える。

## 1. Claude Console（APIキー）
1. https://platform.claude.com を開き、「コダニエイスケ's Individual Org」を選ぶ。
2. ワークスペースを新しくつくる（名前の例：AIインタビュー）。
3. そのワークスペースに、月の使用上限を設定する（例：20ドル）。
4. そのワークスペースでAPIキーを発行し、コピーしておく。キーは人に見せない。

## 2. Googleスプレッドシートと Apps Script
1. Googleドライブで、新しいスプレッドシートをつくる（名前の例：AIインタビュー回答）。
2. メニューの「拡張機能」→「Apps Script」を開く。
3. 最初からある中身を消し、`Code.gs` の中身をすべて貼りつけて保存する。
4. 左の歯車「プロジェクトの設定」→「スクリプト プロパティ」→「プロパティを追加」。
   - プロパティ：`ANTHROPIC_API_KEY`
   - 値：1でコピーしたAPIキー
5. エディタに戻り、関数 `testClaude` を選んで「実行」。初回はGoogleの許可を求められるので許可する。
   - 実行ログに、AIの返事（reply）が出れば成功。

## 3. ウェブアプリとして公開
1. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
2. 次のユーザーとして実行：自分／アクセスできるユーザー：全員。
3. 「デプロイ」を押し、出てきたURL（/exec で終わる）をClaudeに伝える。
4. あとでコードを直したときは「デプロイを管理」→ 編集 →「新バージョン」にすると、URLは変わらない。

## 4. LIFF（LINEの中で開く画面）
LINE Developers のチャネル「2011919996」に、LIFFアプリを追加する。
- 名前：AIインタビュー

- シェアターゲットピッカー：オン

できたLIFF ID をClaudeに伝える。
